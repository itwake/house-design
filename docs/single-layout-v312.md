# V3.1.2：回到一个真正的设计方案

日期：2026-09-10。按业主反馈，原四套的主要差别是饰面与配色，不应作为四个不同布局供选择。

## 当前行为

- 首页直接进入原木「木光原境」查看器，不再出现四卡选集或“换方案”弹窗。
- 保留V3.1.1右侧650×340mm浅鞋柜、左侧7字整墙餐边柜，以及三处飘窗、床向、卫浴和其他空间细节。
- 保留房间导航、平面与柜体立面、15张同源效果图、模型下载、飘窗/收纳专题及说明卡隐藏功能。原木案例来源与材质取舍移到设计说明内，不随着选择器消失。
- `?scheme=terracotta`、`moss`、`cobalt` 是退役配色链接：明确提示后回到原木，并保留有效房间hash、其他查询参数与标签页的说明卡偏好。
- 未知方案ID明确报错，并提供返回原木的入口；不把任意错误链接假装成有效方案。
- UI版本3.1.2，模型与图片`assetRevision`仍为3.1.1。没有修改或重新渲染模型，也没有退回旧版收纳。
- `archivedPalettes`及既有三套模型/图片仅保留为历史材料，当前网站不再加载它们；这不是新设的方案入口。

## 以后什么才算新方案

必须在家具位置、空间功能组织或通行动线上形成有意义的差异，并明确与原案相比的收益、代价、净空与适用生活方式。仅换木色、织物、柜门、五金或灯罩，不单独成为方案。

新的布局需要独立的几何数据、对应2D、3D与同源效果图，逐项核对尺寸和可用性。已有证据确认的墙、门窗和不可更改条件仍要保留；不能把“不同布局”理解为可自行拆改结构。任何实际拆改继续受现场复尺、墙体属性、机电和专业审批条件约束。

历史饰面生成器不是布局生成器；现在必须显式使用`--archived`才能复现。未来增加真实布局，应先设计新的数据分支和校验合同，不能仅去掉原工具的几何保护。
