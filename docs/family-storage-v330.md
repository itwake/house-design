# V3.3.0 · 亲子大件库与餐区重排

第三个独立布局，基于 V3.2.4「暖白套间」。原 `wood`、`suite` 的数据、模型、贴图与效果图不覆盖；本版不是换颜色。入口选择「木光 · 亲子储物」，或者使用 `studio.html?scheme=family&v=3.3.0#dining`。

## 布局与取舍

用户已明确：自行车是儿童车，四人餐桌可以挪位。新方案不改墙体、门窗或卧卫布局，保留书房书架、厨房阳台大窗和暖白浅木材料。

| 部位 | 新布局（模型尺寸，非实测） |
|---|---|
| 入户左侧大件库 | 外包 1630×1500×2500mm，占地约 2.45㎡；不是净储物容量，也不是必须做成800mm深 |
| 柜门 | 向东开口，四叶折叠门，3D展示内折打开状态；名义净开1340mm、高2420mm，无底台 |
| 地面 | 儿童车和折叠婴儿车分开停放，示意模型分别为1100×500×750、750×550×1050mm |
| 西侧上方层架 | 深490mm，第一层台面下沿1300mm，后续间距410mm；九个玩具箱 |
| 四人餐桌 | 仍为1200×700mm及四椅，整体向北950mm、向西250mm |
| 餐边柜 | 取消原7字整墙柜，保留900mm短柜，下柜400mm深、上柜280mm深；台面850mm，中空650mm |
| 右侧鞋柜 | 原位置、尺寸不变 |

换来的大件收纳会明显减少餐边柜容量和连续台面。餐区更靠近客厅；南侧餐椅拉出300mm后，椅背至库体北侧仅约665mm，不作为同时通行的舒适过道。北排东椅与沙发局部仅约180mm，不是通道，往客厅走餐桌西侧。

库体外立面至右鞋柜前沿局部约1200mm；这不表示任何时刻整条玄关都畅通。取车动作会临时占用此空间。

## 取车与使用条件

两辆车仅为明确尺寸的示意，并未获得自家车型、折叠尺寸或实测户型。厂家深化前，测量车轮、把手、脚踏、遮阳棚和折叠锁扣的最外包络。大推车若不折叠，本案不保证容纳。

已用矩形包络分步模拟两辆车向东取出、转90°、向北暂移的路径，共684个取出与转向采样姿态。模拟时入户门保持关闭；车辆先向北移开入户门的扫掠范围，再开入户门。一次取一辆，其他人不要同时穿行。未模拟人体、扶手握持空间、车型转向约束及门外公共走廊，不能当作实际推行、无障碍或消防合规认证。应在现场用纸箱/胶带和实车排演。

四叶门仅建模了打开位置，没有做动态折叠、铰链和轨道的工程验证。落地仍需确认门片宽度、折叠停车空间、轨道净高、防夹、限位及门把手。无底台做法应与地坪及门轨方案共同确认。

层架固定、柜体防倾倒与承重须深化；重物低放，高处只放轻量低频物品，不鼓励孩子攀爬自行取箱。车辆泥沙与餐具分柜腔，底部宜耐擦洗；通风、照明、清洁和可达性由定制设计进一步落实。

## 同源模型与验证

独立源数据在 `models/schemes/family/design-data.json`，Blender/GLB、manifest及贴图同目录，17张直接模型渲染在 `assets/schemes/family/`。既有两方案的196个资产文件以已发布提交 `5a13e8b` 校验保留。源坐标、平面图、柜体部件和车辆包络共享数据。

```powershell
node tools/create_family_storage.mjs
blender --background --threads 2 --python tools/build_family_storage.py -- --render all --engine CYCLES --resolution 960 --samples 8
node tools/test_family_storage.mjs
node tools/test_suite_plan.mjs --family --render
node tools/test_walkthrough.mjs --family
python tools/validate_family_storage.py
python tools/validate_design_schemes.py
node tools/qa_suite_ui.mjs
```

效果图用于观察摆位和材料，并非实测日照模拟。车辆网格的实际导出边界会被单独检查，不仅检查源数据；同时验证原墙体、门窗、书架和无关家具的实际三角面保持不变。浏览器回归覆盖三方案、三种视口及3D/平面/渲染/漫游/收纳近景。

本次本地验证结果：550项方案与渲染来源检查通过，0错误、0待渲染；亲子模型1437个实际网格、25个柜体构件、2辆车包络和38个随餐桌移动的网格核对通过。684个取车/转向采样姿态通过；三方案×三视口共9次真实Chrome会话通过，无页面脚本异常。以上不是工程或实车验收。
