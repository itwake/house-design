## 设计与尺度

| 部位 | 模型尺寸 / 改动 | 取舍与限制 |
| --- | --- | --- |
| A并排洗烘 | 每台600宽×650深×850高，地面独立脚，不叠放 | 650是含门占位假设，具体产品、散热、管线及抽机检修必须再核 |
| 上方台面 / 浅盆 | 台面1680×800，完成面980；浅盆520×740、底880、沿980 | 盆沿偏高；盆底距机顶仅30。只适用于经厂家确认的浅盆后排结构，不适用于普通深台下盆 |
| 独立支撑 | 三片侧板、后梁，右侧检修区 | 不让台面和盆压在洗衣机顶盖上；承重与防震深化 |
| B书架 | 长3180、深300、高2400，底柜＋上方浅木层板 | 固定、防倾倒与承重待专业确认 |
| C阳台推拉门 | 门中线向西287.5，1500洞口，2400高，三轨向南叠停 | 门框外沿与B正面同在x6450；玻璃门扇因轨道内退，不是完全共面 |
| 通道 | 阳台操作带690；沙发到书架700 | 紧凑，一次操作一台机器；实际机门打开后的动作仍待选型试摆 |
| 客厅调整 | 沙发/茶几西移800，电视柜西移400，落地灯避开新柜 | 为B书架前留路，非无代价增加收纳 |
| 厨房窗 | 1200宽×1300高，台高1000，双扇推拉 | 台面980只低20，窗框、收口、防水及龙头需复尺。龙头置窗洞左侧 |

单位mm，均为现有条件模型，非实测。原阳台内净宽1420，两台600机身未必放不下；本版外移门面是为适应整组台面、支撑、检修与齐平设计，不宣称“两台机身必然超宽”。模型阳台约从2.12增至2.54㎡，来自室内面积重新分配，不增加产权面积、不外扩外墙。厨房阳台共墙大窗保留；不把原窗下墙可拆或门垛可改当成已核实事实。
