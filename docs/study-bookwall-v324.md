# V3.2.4 · 书房通长桌上方的浅书架

业主希望利用书桌所在墙做书架，并参考网络设计。本次在暖白套间现有南墙桌上方增加书架，不搬动桌子、椅子、沙发，不改门窗或墙。

## 设计取舍

选择「暖白顶柜＋两排开放格＋下方留空书桌」。不增加落地书柜，不缩短通长桌，也不把书房重新改成床房。低饱和浅木层板与暖白柜体延续已确认的减黄配色；部分书格留空，不做满墙深色木板。

## 施工和使用前提

- 净宽、墙厚、上方梁和设备管线均需现场复尺。不能由模型判断能否吊挂整柜。
- 层板已按短跨分格，但这不代表承重验算通过。板材、书重、背板、挂件、锚栓及基层承载须定制方或相关专业人员设计复核。
- 当前柜体悬挂，不落在桌面上。固定条件不足时必须重做支撑方案，不可直接钻孔照装。
- 顶部是低频收纳，取物要使用合适辅助工具，不可站上桌面；儿童常读书应放在可及低处。本方案不是儿童独立使用高书架的推荐。
- 桌面上留约700mm只是模型间距，不是普适人体工学认证。需要用实际显示器、坐姿、抬头和起身动作试用；书桌550mm进深也需确认设备与视距。
- 柜门目前关闭，需复核开启和取物。灯槽仅表意，色温、功率、眩光、布线和检修未完成照明深化。
