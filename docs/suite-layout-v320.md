# V3.2.0 — 保留原方案，新增主卧套内入口

2026-09-22。依据业主红线示意及其后续确认建立，非施工图或现场量房成果。

## 最终采纳的选择

- 保留原木风格；新增的是墙体、门位和动线方案，不是配色方案。
- 原方案 wood 完整保留；新增方案 suite 拥有独立厘米数据、Blender、GLB、16张同源渲染和漫游。
- 两卧之间的直墙保持原位置；不采用红线最上方的折线分隔。
- 主卧入口先到小玄关：向北到床区、向东入主卫。卧室本身不需要穿过卫生间。
- 主卧床头朝东，床尾西墙衣柜不动；新方案取消主卧飘窗桌、支撑、桌上用品和配椅，保留飘窗本体。
- 业主明确选择次卧衣柜仍留南墙，不实施东墙床尾柜；次卧床和茶座不动，无独立桌椅。
- 外轮廓、三处飘窗、厨房1700mm三轨推拉门、阳台、右鞋柜与左7字餐边柜保持。

## 尺度和必须看见的代价

所有坐标以厘米计，北为图上，东为图右。墙厚暂按120mm；下列均为模型净面积/净空，不是建筑面积或实测值。

| 部位 | 新方案与取舍 |
| --- | --- |
| 两卧分隔 | 墙中心 x=319cm，y=6～328cm；直墙不折、不挪 |
| 主卧小入口 | 净约790×1530mm，保持空净不加柜；入口门洞800mm |
| 主卫门 | 移至西侧，750mm洞口，只通主卧套内入口；封闭旧北门 |
| 公共走廊 | 局部约780mm净宽；北端约1310×880mm转身区 |
| 次卧B | 原东南门厅转为公共转身区；模型面积10.23→9.33㎡，床区及南墙1800×600mm衣柜不动 |
| 书房·客卧 | 东墙下段西移；7.59→6.68㎡，保留床和书桌；椅子调为480×500mm并移位 |
| 主卧计面积 | 床区仍约10.85㎡；新主卧多边形合计约12.15㎡，包含套内入口，不代表床区扩大 |
| 主卫 | 约3.34㎡；盆柜620×360mm放北侧，马桶与淋浴原位 |
| 客卫 | 西侧向公共过道扩展，约3.74㎡；盆柜700×380mm放北侧，马桶与淋浴原位 |
| 客厅学习区 | 固定桌不动；成人活动椅向南150mm，避让走廊转角；儿童椅不动 |

走廊不是额外凭空获得的面积。为避免不动两卧直墙后次卧入口被堵，新方案改变了次卧门厅归属和门位。书房缩小、公共走廊偏窄，均应和原方案对照再决定。

马桶及淋浴模型位置未变，不表示排污、地漏、通气、防水和结构条件已经核准；新客卫地面涉及原干区，尤其需要完整的防水与排水深化。主卧/公共过道门扇的实物门框、门套、开合与家具使用净空仍需现场试放。

范围：

- 实际网页SVG绘制函数的墙、门、房间多边形、三个飘窗与保留衣柜；并将SVG栅格化检查。
- 解析GLB二进制顶点和世界变换，核对57段实墙与5扇重定位门。635个不相关家具网格逐组不变；没有用简单整体包围盒代替墙体检查。

## 不应直接下单施工

先现场确定墙体性质、梁柱/管井、湿区可扩范围与门位条件，再试放780mm走廊、790mm入口及实际门扇。家具使用尺寸、靠墙踢脚线、门套、窗台和儿童防坠仍须专业深化。本轮只完成可比较的概念布局模型，不代表改墙获得批准。
