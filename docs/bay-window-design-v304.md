# 三飘窗：让光线成为日常的一部分

2026-09-08 · V3.0.4 · 荟雅苑28F · 条件设计方案，非施工图。

本次保留主体墙体、两个卫生间的阶梯边界、主卫套内入口，以及主卧床头东、次卧床头西。现代化不只是换窗框：主卧承担办公/梳妆，次卧承担单人休息，客厅承担并肩工作与学习。效果图由同一套厘米数据建立的Blender场景直接渲染，不用生成式图像扩大空间。

## 01 / 主卧：飘窗侧接，不挤进床侧

主卧北墙到床架只有480mm。把600mm深桌板直接伸到这个缝里，再画一张椅子，会穿床或没有坐人的位置。因此采用窗台左端侧接的800×600mm操作桌，完成台高750mm；900mm高窗台占位作为后层板，形成高低台，而不把实台挖成腿洞。

桌面适合一台笔电、小型活动镜及简洁任务灯，办公和梳妆交替使用，不是两项功能同时堆满，也不按大型显示器工位承诺。前沿圆角，桌下取消整排抽屉，浅橡木与无绳卷帘统一。

代价必须看见：西墙衣柜由2200mm缩至1600mm宽，并改移门；椅使用时占局部800mm床尾带，不能承诺同时绕行取衣。桌与床架最近仅20mm，模型能放下不代表订制公差充分，需复尺后调整桌宽/床架外包。衣柜挂衣容量应另由设计师复核。

## 02 / 次卧：一人茶座，不虚构大茶室

北飘窗宽暂1300mm、外凸暂600mm。方案用850×550mm可拆洗暖灰坐垫，侧面留280×320mm可移浅木茶托；靠垫不塞满整个窗腔，避免厚重围边。茶托放杯和常温茶水，不布置烧水炉、电热壶或另一张落地茶几。

**此图只展示低台条件：430mm台顶＋约50mm软垫＝480mm坐面。**原900mm从未测量，仅是旧版模型占位；本次保留`baselineSillCm:90`记录，绝不表示可以把结构台降低470mm。若实测是不可变的高实台，应取消坐人用途、改回陈列台，不加爬梯补救。

床侧仍仅430mm，是紧凑单人使用，不是宽敞休闲平台。台体承载、防水、窗防护及开窗须核验；本方案不是儿童爬台/游戏区。台下没有未经核实的收纳抽屉。

## 03 / 客厅：2米并肩桌，腿位真实留空

2000×650mm浅木长桌设在西飘窗室内侧，台高暂750mm，每人约1000mm桌面。两端及中央细暖灰支架承托，桌下不做连续底柜或抽屉。实际足部空间在室内，不把600mm外凸实台当作可以伸腿的空间。

两张52×52cm椅为占位示意，正常显示位置最东至x337cm，椅后通道按x344–424cm保留800mm；椅继续后拉就会缩窄通道。北侧实墙电视与东侧沙发保留，桌面不改成挡窗的电视柜。

儿童年龄/身高未知，不能把750mm成人台高当成通用学习桌：现场试坐，核对眼距、肘高、背部支持与足部支撑。固定台高不适合时改用分段升降台面，不能仅用高椅把孩子吊在桌前。卷帘应可控西向眩光，桌灯与屏幕位置需现场调试。

## 共同的现代设计语言

浅橡木30mm薄台面、圆角、暖灰细金属、浅色织物与无绳卷帘。高层窗需要实际窗系统方案：细框和减少装饰分格只是拟选外观，不是已经批准改变外立面或拆除窗框受力构件。桌板跨度、连接件、防挠及安装基层由厂家深化，不以渲染中的‘悬浮’证明受力。

## 下单前必须解决

1. 实测三窗的净宽、外凸深度、实台顶高、窗框下沿、墙/台体性质；分别记录，不能三处套同一个高度。
2. 核对可开启扇、把手、卷帘盒、窗台清洁与窗扇扫掠空间；不得让台面/镜子堵住逃生或维护要求。
3. 28楼防坠按新增可攀爬面重新设计。纱窗不是防坠装置，普通渲染玻璃也不是经验证的防护。未通过专业防护、限位及玻璃固定核验前，茶座与儿童窗边学习位不得启用。
4. 让成人/孩子现场用等高桌椅试坐；同时走通床尾、取衣、客厅椅后通道。桌台支撑不占膝部和脚部通道。
5. 出深化图与报价：台面/支架材质厚度、防挠跨度、锚固基层、倒角、软包可拆洗、理线槽与插座数量；所有改动需合格专业人员评估。
