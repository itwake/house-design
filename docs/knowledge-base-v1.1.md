# 装修知识库 V1.1 · 从资料包到业主实战手册

整理日期：2026-09-17。范围仅为知识库，不修改 V3.1.4 的户型、家具、漫游、模型或渲染。

## 本次变化

- 首页由规范目录改为六个当下任务入口：见公司、看报价、逛材料、水电交底、看工地、下单定制。
- 新增34篇实战文章：公司与预算9篇、材料与定制12篇、施工现场11篇、案例阅读与需求转译2篇。
- 新文章包含24张比较表，可复制提问、可勾选清单及个人笔记。来源默认折叠，打印时展开；保留原有14类目录、全文搜索、预算工具、团队比较、10类CSV模板和个人记录导入导出。
- 全站共108篇文章、124条来源记录、397项行动检查。来源记录可能分别指向同一文件的不同章节，不等于124个独立文件。
- 旧文章ID及本机存储格式未变，不重置已有收藏、阅读进度或笔记。

## 用户资料包阅读边界

清点40份文件，37份PDF、PPT/PPTX、XLS/XLSX、DOC/DOCX提取到可用文字，另查看3张PNG。按主题阅读并检查关键页，不宣称对241页PDF和574页PPTX逐页做完整技术审校。课件中存在重复版本；图片内文字可能未完整识别。

PDF及PPTX记录页码或幻灯片范围，表格记录工作表/行列，旧PPT和DOC在无可靠页码时仅标注实际主题。XLS读取的是缓存值，不宣称重新计算或认证过原预算模型。公开网站只保留来源文件名和定位、重新编写的经验文章，不上传整份原文件，不披露验房报告中的个人信息。

旧材料单价、固定工期、旧环保限值、地域化工人刻板判断、闻气味判环保、固定通风天数判入住等没有沿用。异地合同仅启发核对事项，不被当成广州现行合同要求；平台保障营销图不被解释为当前承诺。

## 小红书阅读边界

通过现有浏览器只读查看4篇笔记正文：飘窗书桌、飘窗茶座、广州装修增项自述、广州全包完工复盘。网站分别写清原帖自述、如何迁移到本项目、尚不能证明什么，并提供不含访问令牌的公开原帖链接。部分链接可能要求登录。

没有验证作者身份、广告关系、结算单、投诉真伪或现场效果；没有下载或复用帖子图片。个人金额不外推为广州报价，单方争议不作为公司结论，书桌笔记中的品牌推广和护眼主张不作推荐。

## 本户约束与安全

继续保留七字餐边柜、主卧仅飘窗桌加一椅、次卧茶座无书桌、客厅办公学习长桌的既定偏好；实战文章比较实现方法，不暗中改布局。厨房门洞拓宽、阳台门窗和飘窗仍属待专业核查的条件方案。

水电、燃气、高层门窗、结构及防水由相应专业方确认；业主观察、拍照、表格勾选不是专业验收。文中的73,600元与70,200元对齐报价例为完全虚构的教学算例，相差3,400元，不是市场价、本户预算或商家承诺。
