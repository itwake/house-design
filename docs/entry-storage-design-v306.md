## 玄关：鞋、钥匙与换鞋各有位置

鞋柜1750×400mm，暂高2500mm。奶白哑光上柜，下部用推拉门避免向餐桌扫开；中段1000–1500mm高为浅木置物格，留钥匙、包与充电预留。底部约200mm常鞋空间有落地侧板和分隔支承，不是未经核准的整柜悬浮。

末端设800×400mm单人换鞋凳，完成坐高450mm，软垫可拆洗；木背板配窄镜与挂钩。凳体位于西墙近门末段，不额外放横向屏风或岛台。鞋柜、餐边柜虽用同一配色，内部柜腔分开，不混放鞋与杯盘。

400mm是**柜体外深**，需扣除背板、移门轨道和门板。大尺码鞋按实物长度检查，可调整局部层板形式，不承诺固定存鞋双数。现场必须先量电箱、开关、门铃、对讲与检修口，不能被柜体遮住。

## 餐边：杯盘收纳与干式饮品台

下柜1400×400mm，浅石色台面高850mm；低处是推拉门储物，上方有餐具浅抽屉，示意最大伸出250mm。上柜深280mm，从离地1500mm至2500mm，中间留650mm操作空间。以奶白闭柜为主，南端保留少量开放杯格和暖光。

台面示意保温壶、杯盘、茶罐，没有擅自加水槽、排水或固定大型电器。咖啡机、净饮机等须分别核验机身深度、插头、散热、开盖高度及功率；不得仅凭400mm台面或650mm中空就认定可安装，热蒸汽也不宜直冲上柜。

## 不只是换柜门：同时调整真实动线

原鞋柜前到餐桌西边仅425mm，不能当作正常柜前通道。本轮餐桌和四椅整体向东400mm、向北400mm，桌子本身仍为1200×700mm，吊灯随桌定位。

| 校核关系 | 本轮示意值 | 说明 |
| --- | --- | --- |
| 鞋柜前 → 餐桌西边 | 775mm | 适合紧凑单人取物，不能同时容纳所有开柜/绕行状态 |
| 餐桌东边 → 厨房西墙 | 800mm | 静态边距，不等于任意退椅状态下净通道 |
| 餐边抽屉 + 单人站位 | 250 + 500mm | 与东移后的餐椅分开，仍须实物试用 |
| 换鞋凳膝腿预留 | 向东600mm | 与暂定扫门包络分开，不是新增固定家具 |
| 入户门扫门 | x390..490、y1295..1395cm | 因合页未测，暂保留两种内开的共同包络 |

近门餐椅需推回后再从容进出。人体路径检查只对应明确的模型假设和后退量，不构成无障碍、消防或动态使用验收。墙、窗、厨房门、卫浴、两卧及三处飘窗功能均不改变。

## 实施前复核

- 量房确定柜体净深、门套/梁位、台高、鞋长及常用物清单。
- 高柜、上柜、镜板与坐凳的固定、防倾倒及承载由厂家深化。
- 灯带散热、检修、插座和回路由电气专业确定；图中是设计预留。
- 现场用纸板或胶带模拟餐桌、退椅、开门和换鞋动作，再下单。
