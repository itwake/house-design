# V1.3 · 根据本户背景重排知识内容

2026-09-17。范围仅为装修知识库，不修改三房两卫模型、布局、素材或漫游。

## 内容交付

新增9篇约千字本户实战指南，14张判断/比较表、47项检查、41个追问。内容不是已完成现场检查，而是以业主提供的荟雅苑、28楼、约104㎡、原4位自如租客、10月17日前交付、半包倾向及历史房间需求作出的建议。

- 现在：统一半包询价包、四本预算账、广州及珠三角采购四关口。
- 实际接管现场：逐区交房走查、出租恢复与装修拆旧的七类费用、拆后复核及增减项证据。
- 方案深化：逐房任务卡、两卫与全屋水电更新的边界、三处飘窗与临路窗边体验。

不预设家庭预算、入住期限、每天可看工地，也不虚构小区收费、墙体属性、实际渗漏、线路隐患或必须全部换窗。厨房和阳台条件方案仍服从现行限制，半包分工待具体合同确认。

保留7字整墙餐柜、入门右鞋柜、主卧东床头及飘窗一椅、次卧西床头与茶座、客厅学习长桌、书房与客厅墙、两卫错墙和主卫向卧室门的既定方向。预算取舍比较配置和非必需升级，不擅自以压预算为理由改布局。

## 页面与数据

`house-handover.json`、`house-contract.json`、`house-living.json`包含新增文章。`house-plan.json`为本户建议、三条阅读路径、具体成果及术语解释。`house.mjs`渲染首页推荐与`#house`；`#house/now`、`#house/handover`、`#house/design`能直达对应阶段。

首页优先展示本户指南，通用实战入口折叠但仍可搜索/打开。专用文章有标识、返回入口及同组相关阅读。构建器同时更新完整静态长文版；无新增存储格式，原108篇文章内容及勾选索引完全不变。

## 证据边界

复用此前实际阅读并定位的用户资料与官方来源，来源总数仍为124，不把9篇新分析冒充9个独立外部证据。重新核对广州房屋使用安全管理条例、燃气条例有关条目与官方门窗性能说明；这些只支持对应技术/制度边界，不证明本户现场状态。本轮没有新增小红书帖子或厂家推荐，也没有冒称实地考察。

广东消委会既有合同发布链接本轮网页工具返回错误，不新增关于其附件全文的断言；原来源仍注明此前核验范围。

独立审核修正预算篇可能偏离7字整墙柜布局的表述，并将水电重做明确为用户考虑的情景。各篇至少4个检查、4个问法；来源ID和表格列数已核对。
