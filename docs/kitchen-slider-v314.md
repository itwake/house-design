# V3.1.4 · 厨房拓宽推拉门

2026-09-10。根据业主“厨房门尽可能拓宽，使用推拉门”的要求，在不移动已确认的鞋柜、餐桌、厨房地柜和高柜的条件下，采用1700mm门洞的条件设计。它是当前家具边界下的建议值，**不是结构允许的最大值，也不是可以直接拆墙的施工结论**。

## 这次改了什么

厨房西门中心线仍在平面 `x=536cm`。门洞由 `y1175..1265` 改为 `y1145..1315`，即北扩300mm、南扩500mm，高度仍暂按2200mm。

| 项目 | 本轮模型 |
|---|---:|
| 门洞总宽 | 1700mm，原为900mm |
| 北端剩墙 | 中心线计240mm；从厨房北内墙面计180mm |
| 南端剩墙 | 中心线计800mm；从厨房南内墙面计740mm |
| 门洞南端至右鞋柜北端 | 仅50mm |
| 门洞南端至厨房南地柜北端 | 140mm |
| 推拉形式 | 三扇三轨，北侧洞内叠停；北扇作本次停车基准，另外两扇向北收拢 |
| 外观 | 暖灰细框、透明玻璃、浅内嵌拉手，与现有原木和飘窗细框协调 |

门套若需要更大安装余量，可优先把南端退到 `y1310`，做1650mm洞口、给鞋柜100mm余量；这只是现场深化的备选方向，当前网站仅显示1700mm方案，不增加第二套布局。

## 1700mm不等于1700mm通行宽

本轮是真实的三组门扇边框、玻璃、拉手和错层轨道，不是大玻璃上画两根分格线。

按模型每端38mm边框、两处30mm搭接：框内宽1624mm，单扇宽约561.3mm。收拢时每相邻门扇保留15mm错位，叠停占宽约591.3mm，剩余模型净开约1032.7mm。下单时还需计入缓冲器、止挡、密封、联动五金和安装公差，**约1000mm是深化目标，不是厂家产品保证**。

关闭时三扇在各自轨道上覆盖门洞；进入第一人称漫游时，两扇按几何位移向北叠停，门扇仍可见，北侧停车区也不能穿越。退出漫游恢复关闭位置。其他门保留原先的简化敞开演示。

为什么不做普通两扇对推？相同洞口下，门扇占掉约一半框内宽，改善视觉的幅度大于通行改善。为什么不把门扇完全移到墙外？北侧只有240mm端墙，不够停一扇；南侧则与鞋柜、南侧地柜冲突。当前方案不假设可以凿墙藏门，也不移走业主已确认的柜体。

推拉机构原理参考：[Häfele官方 Metalglas 伸缩玻璃门资料](https://files.hafele.co.uk/catalogfiles/www/16a9-138.pdf)。该资料展示多片玻璃沿轨道收拢及固定/活动片组合；仅作为机制参考，资料较早，不代表本模型已匹配某款在售五金。这里的三轨深度145mm、扇框厚度24mm、玻璃8mm、单扇宽度和轨道固定均为建模参数，须由本地厂家选型、计算及出深化图。

## 现场必须先核对

- 厨房西墙性质、北端剩墙及过梁：是否承重或有结构构件；不能依据示意模型确认可拆。
- 门头轨道固定位置、承载、连接与维修空间，不能仅固定在装饰吊顶上。
- 现有燃气、电线、给排水及门边开关插座，扩洞前先调查路线。
- 鞋柜侧仅50mm：门套、连接件和安装操作是否足够；必要时缩小门洞，而非默认切削鞋柜或墙角。
- 门扇安全玻璃、边框联接、防脱、防夹手、儿童使用、锁止、缓冲、底导向与清洁；6mm示意低导轨并不等于现场无绊倒风险。
- 厨房封闭、通风和燃气使用的现场要求，须让设计、施工和有关服务单位核验。透明玻璃不代表隔声、隔味和气密性能已经合格。
