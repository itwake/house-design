# 装修知识库 V1 · 研究与验证说明

更新：2026-09-17。研究从北京时间9月16日晚开始，跨日完成。

## 内容与范围

- 74篇专题、14类目、约4.8万中文字（统计文章字段，不含来源说明与目录）、267项行动清单。
- 78条来源记录，含政府与标准平台、公共机构、相关企业原始资料和2条本项目记录；同一网址可能为不同适用主张保留不同记录，不代表78个独立研究机构。
- 15条本地考察线索：5家装修公司、3家设计服务、1家检查/造价服务与6个采购渠道。既不排名，也未做实地、信用、财务或履约能力背书。
- 10份CSV空表：需求、报价、工地访谈、采购、机电接口、变更、验收、排期、保修、旧房风险。
- 配套搜索、收藏、阅读进度、行动勾选、私人笔记、预算、团队比较、JSON备份与静态全文版。

文章结构为：为什么要关注、具体怎么比较或推进、行动清单、向服务方提问、常见坑、出处及适用边界。材料报价和公司报价不凭空估计。预算默认15%预备金仅为可编辑的规划占位，不是市场行情或标准。

现有项目模型不是施工图。厨房扩洞、阳台墙体和飘窗改造仍须先核法定限制及现场条件；“全屋重新装修”不能消除共用立管、外墙、结构等全部历史风险。图中已有设计不等于获准施工。

## 资料核验与局限

优先查原始政府、标准状态和厂商资料；企业自有网站标为“企业或厂商官方资料”，不混同政府认可。标准发布日期、实施日期、适用对象和版本分别处理。厂商手册只作为特定产品的原理与安装约束实例，不把该机型参数推广为通用验收值。

关键版本包括：GB 18580-2025已实施、GB/T 39600-2021分级仍现行、GB/T 17790-2025空调安装标准，以及广州2025年施行的房屋使用安全条例和2026年施行的燃气条例。广东2026装修合同仅核验官方发布页与附件入口，未逐条审阅DOCX合同正文，不称已完成法律审查。

个别企业/市场网站和较大PDF直接提取失败时，来源说明已区分官方索引内容、HTTP可访问与完整正文。三星官网历史信息较旧，目录明确标当前营业待核；罗浮宫网页间歇502，不将其公开项目介绍当即时营业保证。没有登录小红书、抓取私人内容或把单帖口碑作为事实。

资料为核验日快照，非持续监控。企业主体、报价、档期、门店、资质、检测能力、供应型号和政策使用前需再次核验。未联系或预约商家，没有商业推广费用。

## 隐私与记录

所有个人记录仅在当前浏览器的`house-design:renovation-kb:v1` localStorage。网站代码没有个人记录上传接口；静态托管访问仍可能由托管方正常记录。清浏览器、无痕窗口或换设备不自动同步。JSON导入会替换当前知识库记录，需要明确确认，不影响3D查看器状态。数据导入校验版本、已知ID、字段长度、数值区间；模板CSV对公式起始字符做转义。

不应在笔记中存身份证、门锁密码或其他敏感信息。公开长文不含用户本机笔记与预算。

## 生成和维护

源内容：`knowledge/data/meta.json`、`start.json`、`companies.json`、`process.json`、`materials.json`、`templates.json`。

```powershell
node tools/build_knowledge.mjs
node tools/test_knowledge.mjs
node tools/test_single_scheme.mjs
```

构建生成`library.json`、`knowledge/guide.html`与10份CSV。结构校验包括分类完整、来源引用闭合、文章和来源ID唯一、模板列数一致、时间与本地链接。

本轮独立Playwright无头浏览器测试本地临时服务：1440×1000、390×844和320×740，135项检查通过，包括74篇逐篇打开、全文搜索、移动目录、阅读/收藏/勾选/笔记刷新保存、预算超支、团队评分的证据门槛、采购目录过滤、CSV与JSON下载、导出清空后导入恢复、静态全文。未使用用户浏览器的私人会话。页面无未捕获异常，测试页面无整体横向溢出；宽表自身可横向滚动。已人工查看首页与文章页面截图。

可在单独安装Playwright后运行`node tools/qa_knowledge.mjs`，启动本项目127.0.0.1:4173临时服务；若Playwright不在仓库依赖路径，可将`PLAYWRIGHT_PACKAGE`设为其`index.mjs`的file URL。本仓库不因此引入生产端依赖，测试截图在被忽略的`tmp/knowledge-qa`。

原设计：132条入口路径、50次查看器初始化回归通过；模型、平面数据、漫游脚本、Three.js资源与渲染资产未改变。只在原查看器顶部加入知识库链接。手机模拟测试不是手机实机或Safari专项认证。
